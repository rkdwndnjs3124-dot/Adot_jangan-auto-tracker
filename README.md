## 1. 코드 핵심 기능 요약
* **기능명**: 자습실 장기 체류자(2.5시간 이상) 자동 모니터링 사이드바
* **주요 기능**:
  * **실시간 조회**: 구글 스프레드시트와 연동하여 당일 자습실에 입실한 지 2.5시간(150분)이 넘은 학생 명단을 사이드바로 자동 추출합니다.
  * **자동 갱신**: 관리자가 매번 확인하지 않아도 10분 주기로 사이드바 화면이 자동 새로고침됩니다.
  * **시각적 알림**: 기준 시간을 초과한 학생이 발생하면 해당 시트 내 셀 배경색을 자동으로 강조(Highlight) 처리하고 경과 시간을 기록합니다.
* **기술 스택**: Google Apps Script (Javascript), HTML/CSS

## 2. 사용 방법 및 환경 설정
* **실행 환경**: Google Spreadsheet (Apps Script)
* **시트 구조 요구사항**:
  * 시트 이름은 요일명(월, 화, 수, 목, 금, 토)으로 되어 있어야 합니다. (일요일은 제외되도록 설계됨)
  * **B열(2번째 열)**: 담당 선생님 이름
  * **C열(3번째 열)**: 학생 이름
